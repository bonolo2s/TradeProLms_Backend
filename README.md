# TradePro LMS (In Progress)

**TradePro LMS** is a comprehensive **Learning Management System** designed to facilitate skill-building, live sessions, and interactive learning, with integrated **advanced journaling and analytics** for traders.

---

## Key Features

- **User Management**: Registration, login, password reset, and profile management with secure authentication (JWT).  
- **Live Sessions**: Scheduling, availability calendar, and management of live classes.  
- **Trade Journal**: Python-based analytics for tracking trades, performance metrics, and reporting.  
- **Backend Architecture**:  
  - Microservices architecture with **CQRS** for separation of commands and queries.  
  - Containerized with **Docker** and orchestrated via **Kubernetes** for scalability.  
  - **CI/CD pipelines** automated with GitHub Actions for smooth deployment.  
- **Frontend**: Built with **Next.js**, **TypeScript**, and **Tailwind CSS** featuring dynamic routing and state management.  
- **Hosting & Cloud**: Deployed on **Azure**, leveraging **PaaS** and **SaaS** depending on service needs.

---

## Technical Stack

- **Backend**: ASP.NET Core, C#, Python  
- **Frontend**: Next.js, TypeScript, Tailwind CSS  
- **Databases**: MongoDB, SQL Server  
- **Infrastructure & DevOps**: Docker, Kubernetes, Azure, GitHub Actions  
- **APIs**: RESTful design with JSON payloads  
- **ORM**: Entity Framework Core  
- **Authentication & Security**: JWT, secure password handling  
- **Architecture Patterns**: Microservices, CQRS
